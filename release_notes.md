## Голос 0.3.1 — виправлення

**Що нового:**
- Після перезавантаження Windows більше не з'являється помилка «Holos.vbs … The system cannot find the file specified». Автозапуск тепер працює через реєстр Windows, старий файл прибирається сам.
- Дрібні виправлення в документації.

**Як оновитись:** якщо «Голос» уже встановлено — програма сама запропонує оновлення. Інакше завантажте `Holos-Setup-0.3.1.exe` нижче й запустіть. Якщо Windows покаже синє вікно «Windows захистила ваш комп'ютер» — натисніть «Докладніше» → «Однаково запустити».

Повний список змін — у [CHANGELOG](https://github.com/canadianproducer/holos/blob/main/CHANGELOG.md).
