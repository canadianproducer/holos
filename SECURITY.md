# Безпека

«Голос» працює локально й нічого не надсилає в інтернет, крім завантаження моделей
і перевірки оновлень на GitHub.

Знайшли вразливість? Не створюйте публічний Issue — напишіть приватно через
вкладку **Security → Report a vulnerability** цього репозиторію.
Підтримується лише остання версія.
